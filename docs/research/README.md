# Research (2026-10-04)

These are multi-agent research runs: Sonnet workers did the research and Opus agents wrote and reviewed the plans. They are for reference only and are not personal financial advice.

| File | What it is |
|---|---|
| `robustness-roadmap.md` | Audit of the codebase plus a phased robustness plan (Phases 0–5). It includes the reviewer's amendments and the backend-engineering appendix. |
| `portfolio-recommendations.md` | Famous-portfolio research, the recommended core, trend and satellite design, risk defaults and platform changes. |
| `data/` | 5-year (Oct 2021 – Sep 2026) monthly IBKR closes and dividends for 11 ETFs, plus the portfolio results computed from them. |
| `backtest.py`, `revised_check.py` | The scripts that produced the 5-year numbers. Run them from this folder. |
| `*-raw.json` | Full structured output of each research run. |

The decisions taken from this research are recorded in `../decisions.md`.
